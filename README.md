# proyecto-tecnologia

## Descripción
Este proyecto fue creado con fines escolares para aprender cómo Git y GitHub permiten organizar, guardar y controlar los cambios durante el desarrollo de un proyecto.

## Objetivo
Comprender y aplicar los conceptos básicos de Git y GitHub mediante la creación de un repositorio, la realización de commits y la organización de un proyecto con README.
